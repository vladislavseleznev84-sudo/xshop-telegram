# Конфиденциальность и хранение данных

> Это техническое описание поведения системы, а не юридическая консультация. Если вы обрабатываете данные людей из ЕС/РФ и т. п., сверьтесь с местным законодательством о персональных данных.

## Принципы

1. **Согласие до обработки.** Для каждого чата отдельно. Пока статус ≠ `granted`: текст сообщений не передаётся в Anthropic и не записывается в долговременную память.
2. **Минимум до согласия.** Хранится только: id чата/сообщения (для дедупликации), зашифрованное имя из Telegram (чтобы показать чат владельцу), время, статус согласия, счётчики событий. Без текста.
3. **Прозрачность.** Первое сообщение чату сообщает, что отвечает AI-ассистент, что текст уходит в Anthropic Claude (США), сколько дней хранится память и как отозвать согласие. Если собеседник искренне спросит «ты человек?» — модель обязана ответить, что она AI-ассистент.
4. **Отзыв и удаление в один шаг.** `/ai_off` (или кнопка «Отозвать согласие») — отзыв + удаление памяти; `/ai_forget` — только удаление памяти; `/ai_on` — запросить согласие заново. Работают даже на паузе и для не разрешённых чатов.
5. **Владелец тоже может удалить**: `/forget <id>`, кнопка «Забыть» в панели.

## Что где хранится

| Данные | Где | Защита | Срок |
|---|---|---|---|
| Текст сообщений (вх./исх.) | `messages.content_enc` | Fernet (AES-128-CBC+HMAC), ключ `ENCRYPTION_KEY` | `retention_days` (по умолчанию 30), затем удаляется ежечасной задачей; сразу при отзыве/«забыть»/удалении сообщения собеседником |
| Профиль собеседника (имя, контекст, договорённости, предпочтения, события) | `profiles.data_enc` | Fernet | до отзыва согласия / «забыть» |
| Имя в Telegram | `chats.name_enc` | Fernet | пока существует чат |
| Журнал событий и расход токенов | `events`, `usage` | без текстов; `detail` — только коды | 90 дней |
| Дедупликация | `seen_messages` (7 дн.), `processed_updates` (3 дн.) | только id | см. слева |
| Токены кнопок и magic-link | `tokens` | одноразовые, TTL 7 дней / 5 минут | удаляются через сутки после истечения |

Профили разных собеседников никогда не смешиваются: каждый запрос к Claude содержит данные **только одного** чата.

## Что уходит в Anthropic

Только для чатов со статусом `granted`: системная инструкция, профиль этого собеседника и последние ≤ 30 сообщений этого чата. Условия обработки и хранения на стороне Anthropic определяются их действующими условиями для API — проверьте их перед запуском. Данные собеседников из чатов без согласия не отправляются никогда.

## Логи

В технических логах нет текстов сообщений, имён и токенов: логируются только типы ошибок и коды. Логгеры `httpx`/`httpcore` понижены до WARNING (иначе в URL попадал бы токен бота). Исключения из обработки апдейтов логируются без текста исключения.

## Доступ

Админ-команды и API панели доступны только владельцу (`OWNER_TELEGRAM_ID`): чужие сообщения боту игнорируются; панель — одноразовая magic-ссылка, выданная ботом владельцу; сессия — подписанная cookie; изменяющие запросы требуют заголовок `X-Requested-With`. Webhook принимает только запросы с верным `X-Telegram-Bot-Api-Secret-Token`.
